Import from photos or screenshots

Import from Instagram / TikTok

Copy the caption from the post and paste it here.

Works with any caption that has Ingredients and Method/Instructions sections. Periods used as line breaks (common on Instagram) are handled automatically.

How to get the caption: Open the post in Instagram/TikTok then tap the "..." menu then Copy text / Copy caption. You can clean it up in a preview before saving.

Select one or more PDF files. One PDF opens in a preview; several are saved straight away as one recipe each. Best results with simple, text-based PDFs.
